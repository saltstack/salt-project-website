The Salt Project is pleased to announce the following bugfix releases of Salt:

* 3006.28 LTS
  * **Release Notes:** View the release notes on [GitHub](https://github.com/saltstack/salt/blob/3006.x/doc/topics/releases/3006.28.md)
  * **Changelogs:** [CHANGELOG.md](https://github.com/saltstack/salt/blob/v3006.28/CHANGELOG.md)
  * **The Tag:** Check out the official ``v3006.28`` tag on [GitHub](https://github.com/saltstack/salt/releases/tag/v3006.28)
  * **Source:** [PyPI - Salt 3006.28](https://pypi.org/project/salt/3006.28/)
* 3007.15 STS (Capstone)
  * **Release Notes:** View the release notes on [GitHub](https://github.com/saltstack/salt/blob/3007.x/doc/topics/releases/3007.15.md)
  * **Changelogs:** [CHANGELOG.md](https://github.com/saltstack/salt/blob/v3007.15/CHANGELOG.md)
  * **The Tag:** Check out the official ``v3007.15`` tag on [GitHub](https://github.com/saltstack/salt/releases/tag/v3007.15)
  * **Source:** [PyPI - Salt 3007.15](https://pypi.org/project/salt/3007.15/)
* 3008.3 LTS
  * **Release Notes:** View the release notes on [GitHub](https://github.com/saltstack/salt/blob/3008.x/doc/topics/releases/3008.3.md)
  * **Changelogs:** [CHANGELOG.md](https://github.com/saltstack/salt/blob/v3008.3/CHANGELOG.md)
  * **The Tag:** Check out the official ``v3008.3`` tag on [GitHub](https://github.com/saltstack/salt/releases/tag/v3008.3)
  * **Source:** [PyPI - Salt 3008.3](https://pypi.org/project/salt/3008.3/)

**Note on 3006.x:** 3006.x releases are now security fixes only. Bugfixes will no longer be backported to the 3006 LTS line, so we recommend planning your move to 3008 LTS.

**Note on 3007.15:** This is a Capstone release, the final release of the 3007 STS line. We recommend planning your move to a supported LTS release, 3006 LTS or 3008 LTS.

## Installation & Upgrade Notes

Users can install Salt via PyPI or through our official package repositories.

* **Install Guide:** Refer to our official instructions for [Installing Salt](https://docs.saltproject.io/salt/install-guide/en/latest/index.html).

* **Package Repo:** Packages are available here:
  * [deb](https://packages.broadcom.com/artifactory/saltproject-deb/)
  * [rpm](https://packages.broadcom.com/artifactory/saltproject-rpm/)
  * [mac](https://packages.broadcom.com/artifactory/saltproject-generic/macos/)
  * [win](https://packages.broadcom.com/artifactory/saltproject-generic/windows/)
  * [onedir](https://packages.broadcom.com/artifactory/saltproject-generic/onedir/)

| IMPORTANT |
| --------- |
| While Salt supports differing versions between the Master and Minions during transitional periods, it is **highly recommended to upgrade your Salt Master first** to prevent compatibility issues. |
